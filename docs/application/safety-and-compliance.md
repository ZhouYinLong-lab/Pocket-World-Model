# 项目安全与合法合规说明

## 当前阶段

PocketWorld 当前只在本地二维模拟器、离线数据和软件评测中运行。当前方法没有获得真实机器人安全认证，不能直接控制真实 Unitree 设备，也不能把 RGB/A* hybrid 的成功率写成纯学习安全证明。

## 后续仿真阶段

- 所有新算法先在离线 replay 和仿真中运行。
- 学习策略之外保留独立的碰撞检测、速度限制、工作空间边界和急停条件。
- 评测记录异常、碰撞、越界、超时和模型失配，不只记录成功率。
- 仿真和真实设备使用不同的日志命名与权限，避免把测试数据误当作训练或最终 holdout。

## 可能的硬件阶段

只有在技术评审通过、低速、隔离区域、人工在场、遥控急停和可恢复状态全部具备时，才考虑小范围硬件观测实验。第一阶段不允许自主高速运动、不允许靠近人员、不允许在公共场所运行、不允许绕过硬件安全限制。

采集数据只记录完成实验所需的图像、状态、动作和时间戳；涉及人员或环境的图像先脱敏，遵守设备供应方和场地的数据管理要求。代码、模型和实验日志按许可证、第三方模型/数据条款和组织安全政策发布。

## 研究诚信

正式 seed、阈值和 OOD 条件在运行前冻结；final holdout 不用于调参；A* fallback 单独标记；正面和负面结果都保留原始 JSON。任何尚未完成的实验在申请材料中标记为 pending，不用 smoke 或推断数字替代。
