# 里程碑与经费预算

建议申请 **1.5 万元分阶段经费**，也可以用等值 GPU、仿真和设备资源替代。金额是项目级预算，不是个人消费计划；每一项都绑定可检查成果。

| 项目 | 建议额度 | 对应工作 | 验收成果 |
|---|---:|---|---|
| GPU 云计算/训练 | 6,000 元 | 三 seed、多条件、多方法 paired formal evaluation；OOD 校准与 bootstrap | JSON 原始结果、图表、运行日志、报告 |
| 仿真与开发环境 | 3,000 元 | 移动机器人连续控制 baseline、噪声/延迟 replay | 仿真环境、baseline、两分钟演示视频 |
| 传感器/小型测试设备 | 4,000 元 | 低风险采集相机噪声、动作延迟和速度估计数据 | 脱敏数据集、采集脚本、安全测试记录 |
| 技术评审与机动预算 | 2,000 元 | 专家评审、版本冻结、必要的实验耗材和存储 | 评审记录、修订协议、release 包 |
| **合计** | **15,000 元** |  |  |

## 分阶段拨付建议

- 第一阶段 5,000 元：完成 formal matrix、校准和失败案例。
- 第二阶段 5,000 元：完成仿真移动机器人和观测噪声/延迟实验。
- 第三阶段 5,000 元：完成安全评审、复现 release、视频和项目总结。

如果宇树能够直接提供 GPU、Unitree 仿真模型、设备或工程师时间，可减少现金需求。资源价值不在于“做出更漂亮的指标”，而在于把当前个人电脑上的小型结论推进到可审查的仿真和低风险观测验证。
