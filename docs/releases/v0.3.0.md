# PocketWorld v0.3.0 — Route-aware probabilistic planning

This release publishes the v8 temporal/probabilistic checkpoint and the complete route-aware barrier revalidation.

## Headline result

Protocol: 50 episodes per seed, seeds `71,83,97`, horizon 48, 1,024 candidates, route-aware objective, 12-step execution prefix, and shift alarms disabled for attribution.

- Imagined success: **92.7% ± 1.9%**
- Real success: **0.667% ± 0.943%**
- Final distance: **29.17 ± 0.51 px**
- Collisions: **5.92 ± 0.41 per episode**
- Route alignment error: **2.505 ± 0.055 px**

The route-aware planner improves the prior real-success boundary from 0% to one successful episode out of 150, but it is not a solved obstacle-navigation system. The result is released as a reproducible negative/partial result for studying imagination-to-execution failure.
