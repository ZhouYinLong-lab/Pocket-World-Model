# PocketWorld v0.1.0

The first reproducible PocketWorld research-prototype release packages the final state-conditioned renderer checkpoint and browser-ready ONNX graph.

## Highlights

- 64×64 RGB Gymnasium environment with inertia, walls, collisions, and goals.
- CNN/GRU image dynamics plus structured position and velocity state.
- Random-shooting and collision-aware planning with imagined-versus-real evaluation.
- Multi-step, OOD, renderer, action-effect, and barrier diagnostics.
- React/TypeScript demo and ONNX Runtime Web inference contract.
- 25 tests and a 70% CI coverage gate; measured coverage at release is 74%.

## Release assets

- `pocketworld-renderer-v5.pt` — PyTorch checkpoint used for renderer evaluation.
- `pocketworld-renderer-v5.onnx` — one-step model with `next_observation` and `next_position` outputs.

## Known limitations

- Pure learned collision planning still achieves 0% real success on the single-barrier benchmark.
- The learned mask head remains an ablation with low shape IoU; deployable RGB uses state-conditioned geometric composition.
- Headline evaluation details are documented in [`docs/evaluation-2026-08.md`](../evaluation-2026-08.md).
