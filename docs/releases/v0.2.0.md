# PocketWorld v0.2.0

This release turns the single-barrier learned-collision result from a documented 0% negative result into a measurable planning milestone.

## Highlights

- 100% imagined / 75% real success on the focused 20-episode single-barrier check.
- Collision-seeking curriculum with corner and world-boundary examples.
- Wall-relative collision-only fine-tuning without degrading the renderer.
- Map-agnostic learned-risk waypoint proposals; no wall-box extraction in pure learned mode.
- Post-impact imagined-state response and continuous peak-risk scoring.
- System identification for acceleration, friction, and speed limit.
- 30 tests and 76% measured line coverage.

## Evaluation scope

The focused result uses seed 71, 20 episodes, horizon 48, and 512 candidates. It is a single-seed research milestone, not yet a replacement for the larger three-seed benchmark. Remaining failures cluster around the narrow top and bottom passages where small velocity uncertainty matters.

## Release assets

- `pocketworld-collision-v5.pt` — PyTorch checkpoint with the learned collision head and calibrated structured kinematics.
- `pocketworld-collision-v5.onnx` — compatible one-step RGB and structured-position graph for ONNX Runtime Web.
